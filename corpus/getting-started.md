# Getting started with TaskNest

TaskNest is a task-management app for small teams. You organize work into
**projects**, and each project holds **tasks** that can be assigned to one
person, given a due date, and marked complete.

To get started:

1. Create an account with your work email.
2. Create your first project from the **New project** button on the home
   screen.
3. Invite your team from **Settings → Members**.
4. Add tasks with the **+ Add task** button inside the project.

TaskNest runs in any modern browser. There are also desktop apps for macOS
and Windows, and mobile apps for iOS and Android. Your data syncs across
all of them automatically — there is nothing to install or configure for
sync to work.
